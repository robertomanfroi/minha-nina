# Minha Nina

Seu WhatsApp conectado ao Claude. Depois de instalado, você pede no chat do Claude:

- "me mostre as conversas que estão esperando resposta"
- "leia a conversa com a Maria e escreva uma resposta"
- "mande para o grupo Clientes VIP: …"

## Como instalar

Não precisa mexer aqui. Instale pela skill **/minha-nina** no Claude (aba Code): ela cria o servidor no
Render, mostra o QR code e entrega o link do conector.

## Como funciona

- Conecta o seu número como "aparelho conectado" (igual ao WhatsApp Web).
- Guarda o texto das conversas por 90 dias no disco do **seu** servidor. Ninguém mais tem acesso.
- Abre um conector para o Claude em `/mcp/<sua-senha>`.

## Cuidados

- Conexão não oficial: envio em massa ou para quem não salvou seu número pode fazer o WhatsApp bloquear o número.
- O link do conector é a senha do seu WhatsApp. Não compartilhe.
- O Claude só age quando você pede no chat. Ele não responde clientes sozinho.
